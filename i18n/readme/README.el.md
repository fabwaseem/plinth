# Plinth — Δωρεάν Ανοιχτού Κώδικα Λήψη YouTube (+ 2000 ιστοτόπους) για Windows, macOS & Linux

Plinth is a free desktop app for Windows, macOS, and Linux. It saves video, audio, playlists, and subtitles from YouTube and 2000+ other [yt-dlp](https://github.com/yt-dlp/yt-dlp) sites onto your computer. MIT licensed. No ads and no usage limits. Install it with [Winget](https://winget.run/pkg/WaseemAnjum/Plinth), [Scoop](https://github.com/fabwaseem/scoop-bucket), [Homebrew](https://github.com/fabwaseem/homebrew-plinth), Flatpak, AppImage, or a direct download.

### Explore: περιήγηση στο YouTube μέσα στο Plinth

- **Καρτέλα Explore** — περιηγηθείτε στο YouTube μέσα στο Plinth και κατεβάστε ό,τι βρείτε χωρίς αντιγραφή συνδέσμων. Το **Λήψη · *το προφίλ σας*** βάζει στην ουρά το βίντεο, την playlist ή το κανάλι που βλέπετε· το βέλος δίπλα αλλάζει προφίλ και η μαγική ράβδος ανοίγει τη λήψη βήμα προς βήμα για επιλογή μορφών, υποτίτλων και άλλων
- **Γραμμή διευθύνσεων** — πληκτρολογήστε για αναζήτηση στο YouTube ή επικολλήστε έναν σύνδεσμο YouTube. Το Explore περιηγείται μόνο στο YouTube, οπότε ένας σύνδεσμος από άλλον ιστότοπο δεν ανοίγει εκεί, αλλά μπορείτε να τον κατεβάσετε με ένα κλικ
- **Λήψεις που χρειάζονται λογαριασμό** — συνδεθείτε μία φορά στο Explore και το Plinth μπορεί να κατεβάζει ιδιωτικά βίντεο και βίντεο μόνο για μέλη που βλέπει ο λογαριασμός σας, βίντεο με περιορισμό ηλικίας αν ο λογαριασμός έχει επαληθευτεί ηλικιακά, καθώς και τις λίστες «Παρακολούθηση αργότερα» και «Μου αρέσουν». Το Plinth εξακολουθεί να κατεβάζει χωρίς σύνδεση και χρησιμοποιεί τη σύνδεσή σας στο Explore μόνο όταν μια λήψη αποτυγχάνει με τρόπο που μπορεί να διορθώσει ένας λογαριασμός. Όταν το YouTube ζητά να επιβεβαιώσετε ότι δεν είστε ρομπότ, το Plinth δοκιμάζει επίσης τη σύνδεσή σας στο Explore
- **Χρησιμοποιήστε δευτερεύοντα λογαριασμό** — η πρώτη οθόνη του Explore εξηγεί γιατί: η λήψη με λογαριασμό ενέχει κάποιο ρίσκο περιορισμού αυτού του λογαριασμού. Αποσυνδεθείτε από το Explore μέσα από τις Ρυθμίσεις όποτε θέλετε να ξεχαστεί η σύνδεση
- **Φραγή διαφημίσεων** — το Explore μπλοκάρει διαφημίσεις και ιχνηλάτες στις δικές του σελίδες· οι λήψεις δεν επηρεάζονται. Είναι ενεργή από προεπιλογή, ένα κλικ στην ασπίδα στη γραμμή εργαλείων του Explore την απενεργοποιεί, και δεν δρα ποτέ στις σελίδες σύνδεσης της Google. Το YouTube μπορεί να αντιδράσει στη φραγή διαφημίσεων για συνδεδεμένους λογαριασμούς

### Ποιότητα & μορφές

- Έως **4K UHD (2160p)**, 1440p, 1080p, 720p, 480p, 360p
- **Υψηλός ρυθμός καρέ** διατηρείται ως έχει — 60 fps, 120 fps, HDR
- **Ήχος** — εξαγωγή μόνο ήχου σε MP3, M4A/AAC, Opus ή WAV. Στις διαδραστικές λήψεις, επίλεξε τα εγγενή κομμάτια surround/Dolby της πηγής (AC-3, E-AC-3, 5.1, DRC) όταν είναι διαθέσιμα, ή όρισε μια καθολική προεπιλογή **Προτίμηση surround / Dolby**
- Γρήγορες προεπιλογές: *Καλύτερη ποιότητα* · *Ισορροπημένη* · *Μικρό αρχείο*

### Ροή εργασίας

- **Καθολική συντόμευση λήψης** — αντίγραψε έναν σύνδεσμο σε οποιαδήποτε εφαρμογή και πάτησε `Ctrl+Shift+D` (`Cmd+Shift+D` σε macOS)· το Plinth τον βάζει στην ουρά με το ενεργό σου προφίλ χωρίς να ανοίξει το παράθυρο, και μια ειδοποίηση το επιβεβαιώνει. Ενεργή από προεπιλογή, με δυνατότητα αλλαγής
- **Ευέλικτοι τρόποι εκκίνησης** — διάλεξε καθοδηγούμενη μεμονωμένη λήψη, επιλογέα playlist/καναλιού, μαζική επικόλληση URL, Quick Download με αποθηκευμένες προεπιλογές ή περιήγηση και λήψη από το Explore
- **Κεντρική ουρά λήψεων** — κάθε μεμονωμένη, playlist, μαζική ή γρήγορη εργασία καταλήγει σε ένα σημείο για πρόοδο, παύση, συνέχιση, ακύρωση, επανάληψη και έλεγχο προτεραιότητας
- **Παρακολούθηση πρόχειρου** — αντιγράψτε έναν σύνδεσμο YouTube και το Plinth συμπληρώνει αυτόματα το URL όταν εστιάζετε ξανά στην εφαρμογή (εναλλαγή στις Σύνθετες ρυθμίσεις)
- **Αυτόματη εκκαθάριση URL** — αφαιρεί παραμέτρους παρακολούθησης (`si`, `pp`, `utm_*`, `fbclid`, `gclid`) και ξετυλίγει συνδέσμους `youtube.com/redirect`
- **Λειτουργία δίσκου** — το κλείσιμο του παραθύρου διατηρεί τις λήψεις στο παρασκήνιο
- **30 γλώσσες** — εντοπίζει αυτόματα τη γλώσσα συστήματος, με αλλαγή οποιαδήποτε στιγμή
- **Συγχρονισμός playlist** — ξανασαρώνει μια playlist σε σχέση με έναν τοπικό φάκελο για να παραλείψει ήδη κατεβασμένα βίντεο· δημιουργεί ένα αρχείο playlist `.m3u` που ενημερώνεται καθώς κατεβαίνει κάθε βίντεο
- **Έλεγχοι ταχύτητας και ρυθμού** — περιόρισε το bandwidth λήψης, όρισε πόσα μέρη ενός βίντεο κατεβαίνουν ταυτόχρονα και πρόσθεσε καθυστερήσεις αιτημάτων με προεπιλογές (*Ανενεργό · Ισορροπημένο · Προσεκτικό · Προσαρμοσμένο*)
- **Πρότυπα ονομάτων αρχείων** — ονομάστε τις λήψεις όπως θέλετε με `{title}`, `{uploader}`, `{id}`, `{date}`, `{resolution}` και `{playlist_index}`, καθολικά ή ανά προφίλ λήψης
- **Ταυτόχρονες λήψεις και αυτόματη επανάληψη** — διάλεξε πόσες λήψεις της ουράς τρέχουν ταυτόχρονα και άσε το Plinth να επαναλάβει μια λήψη που συνάντησε πρόβλημα δικτύου ή διακομιστή, περιμένοντας περισσότερο πριν από κάθε προσπάθεια
- **Προφίλ ανά βίντεο σε playlist** — αναθέστε σε κάθε βίντεο μιας playlist το δικό του προφίλ λήψης αντί για μία ρύθμιση για ολόκληρη τη λίστα, ώστε ένα πέρασμα να αρχειοθετεί κάποια σε πλήρη ποιότητα και να παίρνει τα υπόλοιπα ως MP3
- **Το Quick Download λειτουργεί στο παρασκήνιο** — ο σύνδεσμος εμφανίζεται αμέσως στις Λήψεις και προετοιμάζεται εκεί, μια ειδοποίηση με **Προβολή** το επιβεβαιώνει και το πεδίο URL καθαρίζει για τον επόμενο σύνδεσμο. Ξεκινήστε όσους θέλετε ενώ προετοιμάζονται οι προηγούμενοι
- **Οι Λήψεις σας λένε τι χρειάζεται εσάς** — αν το Plinth δεν μπορεί να διαβάσει έναν σύνδεσμο, η γραμμή του εξηγεί γιατί και προτείνει τη λύση: Επανάληψη, ενεργοποίηση cookies ή σύνδεση στο Explore. Με τα cookies απενεργοποιημένα, το **Σύνδεση με Explore** τον ξαναδοκιμάζει για εσάς μόλις συνδεθείτε. Μια playlist μεγαλύτερη από το όριο φόρτωσης περιμένει στη γραμμή της να επιλέξετε ολόκληρη, τα πρώτα στοιχεία ή έλεγχο. Η καρτέλα Λήψεις μετρά τις γραμμές που σας περιμένουν

### Υπότιτλοι & μετεπεξεργασία

- **Υπότιτλοι** σε SRT, VTT ή ASS — χειροκίνητοι ή αυτόματα δημιουργημένοι, σε οποιαδήποτε διαθέσιμη γλώσσα
- Αποθήκευση δίπλα στο βίντεο, ενσωμάτωση σε `.mkv`, ή οργάνωση σε υποφάκελο `Subtitles/`
- **SponsorBlock** — παράλειψη ή επισήμανση κεφαλαίου για χορηγούς, εισαγωγές, εξόδους, αυτο-προωθήσεις
- **Ενσωματωμένα μεταδεδομένα** — τίτλος, ημερομηνία μεταφόρτωσης, κανάλι, περιγραφή, μικρογραφία και δείκτες κεφαλαίων γραμμένα στο αρχείο
- **Παρτίδες μόνο υποτίτλων** — επικολλήστε μια λίστα URL ή ανοίξτε μια λίστα αναπαραγωγής, επιλέξτε Υπότιτλοι και πάρτε μόνο τα αρχεία υποτίτλων για κάθε βίντεο

### YouTube + 2000 ιστοτόποι

- **YouTube, πλήρως** — βίντεο, Shorts, κανάλια, playlists, YouTube Music και podcasts χειρίζονται ως πρωτεύουσες πηγές
- **2000+ άλλοι ιστοτόποι** μέσω yt-dlp — Vimeo, Twitch, Twitter/X, TikTok, SoundCloud, Bandcamp, Bilibili, BBC iPlayer, archive.org και πολλοί άλλοι
- **Μόνο ήχος και υπότιτλοι** λειτουργούν σε κάθε υποστηριζόμενο ιστοτόπο, όχι μόνο στο YouTube
- Αν ένας ιστοτόπος αλλάξει, το yt-dlp παρέχει διορθώσεις εβδομαδιαία και το Plinth ενημερώνει αυτόματα το εκτελέσιμο κατά την εκκίνηση

### Απόρρητο & έλεγχος

- 100% τοπική επεξεργασία — οι λήψεις πηγαίνουν απευθείας από το YouTube στον δίσκο σας
- Χωρίς σύνδεση, χωρίς cookies, χωρίς συνδεδεμένο λογαριασμό Google
- Αρχεία αποθηκευμένα απευθείας στον φάκελο που επιλέγετε

## <a id="install"></a>Εγκατάσταση και πρώτη εκκίνηση

**Windows**

```bash
winget install WaseemAnjum.Plinth
```

**macOS**

```bash
brew install --cask fabwaseem/plinth/plinth
```

**Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/fabwaseem/plinth/main/scripts/install.sh | sh
```

Flatpak:

```bash
curl -fsSL https://raw.githubusercontent.com/fabwaseem/plinth/main/scripts/install.sh | sh -s -- --flatpak
```

Οι εκδόσεις είναι μόνο x86_64. Χωρίς `curl`; Αντικαταστήστε το `curl -fsSL` με `wget -qO-`.

### <a id="windows-first-launch"></a>Windows — πρώτη εκκίνηση

Κατά την πρώτη εκκίνηση μπορεί να δείτε **"Windows protected your PC"** ή **"Unknown publisher."** Αυτό ισχύει τόσο για το `Plinth-win-x64-Setup.exe` όσο και για το `Plinth-win-x64-Portable.exe`. Το Plinth είναι δωρεάν και ανοιχτού κώδικα και τα Windows builds δεν είναι υπογεγραμμένα με επί πληρωμή πιστοποιητικό, γι' αυτό το SmartScreen τα επισημαίνει. Αυτό **δεν** σημαίνει αυτόματα ότι το Plinth είναι επικίνδυνο. Για να συνεχίσετε:

<img src="../../build/win-smartscreen-more-info.png" width="420" alt="Παράθυρο SmartScreen "Windows protected your PC" με τον σύνδεσμο "More info" επισημασμένο" />
<img src="../../build/win-smartscreen-run-anyway.png" width="420" alt="Παράθυρο SmartScreen μετά την ανάπτυξη του More info, που δείχνει το κουμπί "Run anyway"" />

1. Κάντε κλικ στο **More info**.
2. Κάντε κλικ στο **Run anyway**.

#### Αν το Windows Defender επισημάνει ή αφαιρέσει το αρχείο

Τα ευρετικά του Defender επισημαίνουν μερικές φορές ανυπόγραφα NSIS installers και Electron portables ως ύποπτα. Αν ο Defender βάλει σε καραντίνα το `Plinth-win-x64-Setup.exe` ή το `Plinth-win-x64-Portable.exe`, επαναφέρετέ το από **Windows Security → Virus & threat protection → Protection history**, και στη συνέχεια προσθέστε το εκτελέσιμο αρχείο του Plinth ως επιτρεπόμενο στοιχείο στο **Manage settings → Add or remove exclusions**. Όπως και με το SmartScreen, η αιτία είναι η έλλειψη υπογραφής εκδότη, όχι εντοπισμός κακόβουλου λογισμικού.

> Κατεβάστε το Plinth μόνο από την επίσημη σελίδα GitHub Releases. Αν το αρχείο προήλθε από άλλη ιστοσελίδα ή σας το έστειλε κάποιος, διαγράψτε το και κατεβάστε αντίγραφο από την επίσημη πηγή. Ο πηγαίος κώδικας είναι δημόσιος, οπότε μπορείτε να τον ελέγξετε ή να φτιάξετε το Plinth μόνοι σας αν προτιμάτε.

Προτιμάτε το Scoop; `scoop bucket add plinth https://github.com/fabwaseem/scoop-bucket && scoop install plinth`

### <a id="macos-first-launch"></a>macOS — πρώτη εκκίνηση

Το Plinth δεν έχει ακόμα υπογραφεί ψηφιακά για macOS, οπότε το Gatekeeper μπορεί να εμφανίσει το τρομακτικό μήνυμα *"Plinth.app is damaged and can't be opened"* μετά την εγκατάσταση από το DMG. Αυτό σημαίνει ότι το macOS έθεσε σε quarantine μια μη υπογεγραμμένη εφαρμογή· δεν σημαίνει ότι τα αρχεία της εφαρμογής είναι πραγματικά κατεστραμμένα. Στα τρέχοντα macOS, η αξιόπιστη λύση είναι το Terminal:

1. Σύρετε το `Plinth.app` από το τοποθετημένο DMG στον φάκελο `/Applications`.
2. Ανοίξτε το Terminal και εκτελέστε αυτές τις δύο εντολές:

```bash
xattr -dr com.apple.quarantine /Applications/Plinth.app
open /Applications/Plinth.app
```

Η πρώτη εντολή αφαιρεί το χαρακτηριστικό quarantine από το εγκατεστημένο αντίγραφο του Plinth. Η δεύτερη ξεκινά την εφαρμογή. Το `sudo` μπορεί να ζητήσει τον κωδικό του Mac σας· το Terminal δεν εμφανίζει χαρακτήρες όσο τον πληκτρολογείτε.

**Apple Silicon έναντι Intel:** σε Mac με επεξεργαστή M-series (M1 / M2 / M3 / M4), κατεβάστε το DMG `arm64`. Σε Intel Mac, κατεβάστε το DMG `x64`. Η εκτέλεση του λάθος build λειτουργεί μέσω Rosetta αλλά είναι αισθητά πιο αργή.

> Τα builds για macOS παράγονται μέσω CI σε Apple Silicon και Intel runners. Αν αντιμετωπίσετε προβλήματα, παρακαλώ [ανοίξτε ένα ζήτημα](../../issues) — τα σχόλια χρηστών macOS διαμορφώνουν ενεργά τον κύκλο δοκιμών macOS.

### <a id="why-warning"></a>Γιατί μπορεί να δείτε προειδοποίηση

Το Plinth είναι ανοιχτού κώδικα και αδειοδοτημένο με MIT. Τα builds για Windows και macOS **δεν υπογράφονται ψηφιακά** — τα πιστοποιητικά Apple Developer ID και Windows EV code-signing κοστίζουν εκατοντάδες δολάρια το χρόνο, που ένα indie project πληρώνει από την τσέπη του. Χωρίς αυτές τις υπογραφές, το Windows SmartScreen και το macOS Gatekeeper θα σας προειδοποιήσουν κατά την πρώτη εκκίνηση. Οι προειδοποιήσεις σημαίνουν *ότι το OS σας δεν αναγνωρίζει τον εκδότη* — δεν σημαίνουν ότι το Plinth είναι κακόβουλο λογισμικό.

Τρεις τρόποι να επαληθεύσετε το Plinth μόνοι σας, με αυξανόμενη αυστηρότητα:

- **Διαβάστε τον πηγαίο κώδικα.** Κάθε γραμμή βρίσκεται στο [GitHub](https://github.com/fabwaseem/plinth) και μπορείτε να [κατασκευάσετε από τον πηγαίο κώδικα](#tech).
- **Ελέγξτε το SHA256.** Αντιστοιχίστε το αρχείο σας με το δημοσιευμένο [`SHA256SUMS`](../../releases/latest) — δείτε παρακάτω [Επαληθεύστε τη λήψη σας](#verify).
- **Εκτελέστε σάρωση τρίτου.** Ανεβάστε το αρχείο στο [VirusTotal](https://www.virustotal.com).

### <a id="linux-first-launch"></a>Linux — πρώτη εκκίνηση

Τα AppImage εκτελούνται απευθείας — χωρίς εγκατάσταση. Απλά πρέπει να επισημάνετε το αρχείο ως εκτελέσιμο.

**Διαχειριστής αρχείων:** δεξί κλικ στο `.AppImage` → **Ιδιότητες** → **Δικαιώματα** → ενεργοποιήστε **Να επιτρέπεται η εκτέλεση αρχείου ως πρόγραμμα**, στη συνέχεια διπλό κλικ.

**Terminal:**

```bash
chmod +x Plinth-linux-x64.AppImage
./Plinth-linux-x64.AppImage
```

Αν η εκκίνηση εξακολουθεί να αποτυγχάνει, τρέξτε το χωρίς προσάρτηση — δεν χρειάζεται πακέτο FUSE:

```bash
./Plinth-linux-x64.AppImage --appimage-extract-and-run
```

**Προαιρετική ενσωμάτωση επιφάνειας εργασίας:** εγκαταστήστε μία φορά το [AppImageLauncher](https://github.com/TheAssassin/AppImageLauncher) και κάθε AppImage που κάνετε διπλό κλικ καταχωρείται αυτόματα στο μενού εκκίνησής σας — δεν χρειάζεται χειροκίνητο αρχείο `.desktop`.

**Απλό αρχείο tar (χωρίς FUSE, χωρίς εγκατάσταση):**

Η έκδοση `.tar.gz` είναι η ίδια εφαρμογή χωρίς το περίβλημα AppImage — αποσυμπιέστε την οπουδήποτε και τρέξτε την. Χωρίς πρόγραμμα εγκατάστασης και χωρίς πακέτο FUSE.

```bash
tar xzf Plinth-linux-x64.tar.gz
./Plinth-linux-x64/plinth
```

**Τα αρχεία Linux στη σελίδα εκδόσεων είναι μόνο x86_64.** Σε μηχανήματα ARM64 (Raspberry Pi, Asahi Linux) το Flatpak εγκαθίσταται αλλά αποτυγχάνει στην εκκίνηση με `bwrap: execvp ldconfig: Exec format error`.

Κάθε έκδοση δημοσιεύει ένα αρχείο `SHA256SUMS` μαζί με τα δυαδικά αρχεία. Για να ελέγξετε ότι η λήψη σας δεν έχει αλλοιωθεί ή τροποποιηθεί κατά τη μεταφορά, κάντε hash το αρχείο σας τοπικά και αντιστοιχίστε τη γραμμή στο `SHA256SUMS`. Ανοίξτε τη σελίδα τελευταίας έκδοσης → **Assets** → κατεβάστε το `SHA256SUMS`.

**Windows (PowerShell ή Command Prompt):**

```powershell

```

**macOS (Terminal):**

```bash
shasum -a 256 Plinth-mac-arm64.dmg
```

**Linux (Terminal):**

```bash
sha256sum Plinth-linux-x64.AppImage
```

## <a id="privacy"></a>Απόρρητο

Οι λήψεις γίνονται απευθείας μέσω [yt-dlp](https://github.com/yt-dlp/yt-dlp) από το YouTube στον φάκελο που επιλέγετε — τίποτα δεν δρομολογείται μέσω τρίτου διακομιστή. Το ιστορικό παρακολούθησης, το ιστορικό λήψεων, τα URL και τα περιεχόμενα αρχείων παραμένουν στη συσκευή σας.

Το Plinth στέλνει ανώνυμη, συγκεντρωτική τηλεμετρία μέσω [OpenPanel](https://openpanel.dev) — μόνο ό,τι χρειάζεται για σφάλματα, καταρρεύσεις, σχόλια, OS και εκδόσεις εφαρμογής. Χωρίς URLs, τίτλους βίντεο, διαδρομές αρχείων, στοιχεία λογαριασμού, fingerprinting ή προσωπικά δεδομένα. Το αναγνωριστικό ανά εγκατάσταση είναι τυχαίο και δεν συνδέεται με την ταυτότητά σας. Μπορείτε να το απενεργοποιήσετε στις Ρυθμίσεις.

Το Explore κρατά τη δική του σύνδεση, ξεχωριστή από το πρόγραμμα περιήγησής σας, και το Plinth δεν διαβάζει ούτε συμπληρώνει ποτέ τη φόρμα σύνδεσης — πληκτρολογείτε στη σελίδα της ίδιας της Google. Οι λήψεις γίνονται χωρίς σύνδεση· μόνο όταν μία αποτύχει με τρόπο που μπορεί να διορθώσει ένας λογαριασμός, το Plinth διαβάζει εκ νέου τη σύνδεση, την κρατά σε προσωρινό αρχείο για εκείνη τη λήψη και διαγράφει το αρχείο μετά. Η αποσύνδεση από το Explore στις Ρυθμίσεις την ξεχνά.

## <a id="faq"></a>Συχνές Ερωτήσεις

**Είναι πραγματικά δωρεάν;**
Ναι — άδεια MIT, χωρίς premium επίπεδο, χωρίς περιορισμούς λειτουργιών.

**Ποιες ποιότητες βίντεο μπορώ να κατεβάσω;**
Ό,τι παρέχει το YouTube: 4K UHD (2160p), 1440p, 1080p, 720p, 480p, 360p, καθώς και μόνο ήχο. Ροές 60 fps, 120 fps και HDR διατηρούνται ως έχουν.

**Μπορώ να εξάγω μόνο τον ήχο ως MP3;**
Ναι. Επίλεξε *μόνο ήχος* στο μενού μορφής και μετά MP3, M4A/AAC, Opus ή WAV.

**Πώς κατεβάζω βίντεο που χρειάζονται λογαριασμό YouTube;**
Συνδεθείτε μία φορά στην καρτέλα Explore. Το Plinth μπορεί τότε να κατεβάζει ιδιωτικά βίντεο και βίντεο μόνο για μέλη που βλέπει ο λογαριασμός σας, βίντεο με περιορισμό ηλικίας αν ο λογαριασμός έχει επαληθευτεί ηλικιακά, καθώς και τις λίστες «Παρακολούθηση αργότερα» και «Μου αρέσουν». Χρησιμοποιεί τη σύνδεση μόνο όταν μια λήψη αποτυγχάνει με τρόπο που μπορεί να διορθώσει ένας λογαριασμός· όλα τα υπόλοιπα κατεβαίνουν όπως πριν. Αυτή είναι η επιλογή **Σύνδεση Explore**, πρώτη στη λίστα και με την ένδειξη «Προτείνεται» στις ρυθμίσεις cookies, και το Plinth την επιλέγει για εσάς την πρώτη φορά που ανοίγετε το Explore. Το wiki του yt-dlp σημειώνει ότι [η αυτοματοποίηση με σύνδεση μπορεί να επισημάνει έναν λογαριασμό Google](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies), οπότε ένας δευτερεύων λογαριασμός είναι η ασφαλέστερη επιλογή.

**Θα συνεχίσει να λειτουργεί όταν το YouTube αλλάξει κάτι;**
Το yt-dlp ενημερώνεται αυτόματα κατά την εκκίνηση, και το Plinth κυκλοφορεί διορθώσεις άμεσα όταν το YouTube αλλάζει κάτι. Όταν το YouTube ζητά να επιβεβαιώσετε ότι δεν είστε ρομπότ, το Plinth δοκιμάζει και τη σύνδεσή σας στο Explore αν έχετε συνδεθεί εκεί, ενώ cookies από αρχείο ή από το πρόγραμμα περιήγησής σας είναι διαθέσιμα στις ρυθμίσεις cookies.

**Σε ποιες γλώσσες είναι διαθέσιμο το Plinth;**
30 γλώσσες είναι διαθέσιμες από την αρχή: Afaan Oromoo · Bahasa Indonesia · Deutsch · English · Español · Français · Italiano · Kiswahili · O'zbekcha · Polski · Português · Tiếng Việt · Türkçe · አማርኛ · العربية · اردو · پښتو · فارسی · বাংলা · हिन्दी · ไทย · မြန်မာဘာသာ · Ελληνικά · Русский · Српски · Українська · 中文 · 日本語 · 한국어 · 繁體中文. Το Plinth εντοπίζει αυτόματα τη γλώσσα του λειτουργικού συστήματος στην πρώτη εκκίνηση και μπορείς να αλλάξεις γλώσσα οποιαδήποτε στιγμή από τον επιλογέα στη γραμμή εργαλείων. Τα Runtime locale JSON βρίσκονται στο src/shared/i18n/locales/, και οι κατάλογοι PO για μεταφραστές βρίσκονται στο i18n/locales/ — άνοιξε PR στο GitHub για να συνεισφέρεις.

**Χρειάζεται να εγκαταστήσω κάτι άλλο;**
Όχι. Το yt-dlp κατεβαίνει αυτόματα στην πρώτη εκκίνηση και αποθηκεύεται στον υπολογιστή σας· το ffmpeg και το ffprobe περιλαμβάνονται στην εφαρμογή. Μετά από αυτό δεν απαιτείται καμία επιπλέον ρύθμιση.

**Μπορώ να κατεβάσω λίστες αναπαραγωγής ή ολόκληρα κανάλια;**
Ναι — και τα δύο. Επικόλλησε URL playlist ή καναλιού (π.χ. `youtube.com/@handle`, `/channel/UC…`, `/c/Name`, `/user/Old`), διάλεξε πόσες εγγραφές θα σαρωθούν και μετά βάλε όλη τη λίστα στην ουρά ή επίλεξε συγκεκριμένα βίντεο. Τα φίλτρα εύρους ημερομηνιών έρχονται σύντομα.

**Το macOS λέει "η εφαρμογή είναι κατεστραμμένη" — τι να κάνω;**
Αυτό είναι το macOS Gatekeeper που αποκλείει μια μη υπογεγραμμένη εφαρμογή, όχι πραγματική βλάβη. Δείτε το [macOS first launch](#macos-first-launch) για τις εντολές Terminal που αφαιρούν το quarantine και ξεκινούν το Plinth.

**Είναι νόμιμη η λήψη βίντεο YouTube;**
Για προσωπική, ιδιωτική χρήση γίνεται γενικά αποδεκτή στις περισσότερες δικαιοδοσίες. Είστε υπεύθυνοι για τη συμμόρφωση με τους [Όρους Χρήσης](https://www.youtube.com/t/terms) του YouTube και τους τοπικούς νόμους πνευματικής ιδιοκτησίας.

## Troubleshooting

### App won't open / no window appears

The Plinth process starts but no window shows up. Most often this is a GPU driver hang during startup.

**1. Check the log.**

| Platform | Path |
| --- | --- |
| Windows | `%APPDATA%\Plinth\logs\main.log` |
| macOS | `~/Library/Logs/Plinth/main.log` |
| Linux | `~/.config/Plinth/logs/main.log` |

**2. Launch with hardware acceleration disabled.**

```bash
# Windows (Portable) — PowerShell
.\Plinth-win-x64-Portable.exe --disable-gpu

# Windows (Installed)
"%LOCALAPPDATA%\Programs\Plinth\Plinth.exe" --disable-gpu

# macOS
/Applications/Plinth.app/Contents/MacOS/Plinth --disable-gpu

# Linux (AppImage)
./Plinth-linux-x64.AppImage --disable-gpu
```

**3. Persist the flag via `argv.json`.**

| Platform | Path |
| --- | --- |
| Windows | `%APPDATA%\Plinth\argv.json` |
| macOS | `~/Library/Application Support/Plinth/argv.json` |
| Linux | `~/.config/Plinth/argv.json` |

```json
{ "disable-hardware-acceleration": true }
```

**4. Other flags worth trying:** `--disable-software-rasterizer`, `--disable-gpu-sandbox`, `--in-process-gpu`.

**5. Stale window position.** Delete `<userData>\window-state.json` and relaunch.

**6. Still stuck?** Open an issue with your OS version and any output from `--enable-logging --v=1`. If the window does open, attach the file from **Settings → Save diagnostics file**.
